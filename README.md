# What Makes Me Tired? A Data-Driven Analysis of My Daily Habits

## Project Overview
This project explores the relationship between my daily habits and my perceived tiredness. As a university student, I often experience different levels of tiredness throughout the week, and I want to understand which factors might influence how I feel.

By collecting and analyzing personal daily data, I aim to identify patterns and relationships between tiredness and different aspects of my routine, such as sleep, physical activity, screen time, and academic activities.

This project is part of the Massive Data Mining course at Universitat Pompeu Fabra (UPF).

## Research Objectives
The main objectives of this project are:
- Explore the relationship between sleep habits and daily tiredness.
- Investigate whether physical activity, screen time, and academic routines are associated with tiredness.
- Identify patterns in my daily habits using data analysis techniques.
- Reflect on how the results could help me better understand my personal routine.

My initial hypotheses were that sleeping less, studying more, spending more time on screens and doing more physical activity would be associated with higher tiredness.

## Dataset
The dataset (`data/Why_Am_I_So_Tired_final.xlsx`, sheet `Daily data`) contains personal observations that I collected manually every day from **October 5 to November 22, 2026** (49 days, one row per day). There are no missing values in the main variables and no duplicated dates. The data only describe me; no other person is identifiable.

| Variable | Description |
|---|---|
| `date` | Date of the day |
| `university_day` | Scheduled university day (Yes/No) |
| `class_hours` | Hours of class |
| `study_hours` | Hours of individual study |
| `bedtime` | Time I went to bed (night before) |
| `wake_up_time` | Time I woke up |
| `sleep_hours` | Hours of sleep the night before, from falling asleep to waking up |
| `nap_duration_min` | Nap duration (minutes) |
| `screen_time_hours` | Total screen time (hours) |
| `screen_before_bed_min` | Screen use before going to sleep (minutes, night before) |
| `gym_duration_min` | Time at the gym (minutes) |
| `steps` | Daily steps |
| `tiredness` | Tiredness during the day, rated every evening from 1 (not tired) to 5 (very tired) |
| `notes` | Short personal notes about special events (e.g. party, sick); empty on most days |

## Methodology
The analysis is in `tiredness_analysis.ipynb` and follows these steps:

1. **Data loading and preprocessing:** type conversion and checks for missing values and duplicates. No observation is removed.
2. **Feature engineering:** total academic hours (class + study), total sleep (night sleep + nap), a weekend indicator, and an event type (party / sick / normal) taken from my notes.
3. **Exploratory analysis:** distribution and evolution of tiredness, and comparison between university and non-university days and between weekdays and weekends.
4. **Correlation analysis:** Pearson and Spearman correlations with p-values (Spearman is the main measure because tiredness is ordinal), plus a sensitivity analysis without the 9 exceptional days.
5. **Temporal analysis:** 3-day rolling averages of sleep and academic workload, and a check with windows from 1 to 7 nights.
6. **Clustering:** K-means on seven standardized habit variables (tiredness is not used), with the elbow method, silhouette score, Kruskal–Wallis test and a stability check.

## Reproducibility

**Option 1: Google Colab**
1. Open `tiredness_analysis.ipynb` in Google Colab (File → Open notebook → GitHub, and paste the repository URL).
2. Upload `data/Why_Am_I_So_Tired_final.xlsx` to the Colab session.
3. Run all cells (Runtime → Run all).

**Option 2: Local**
```bash
git clone https://github.com/martacampas/what-makes-me-tired.git
cd what-makes-me-tired
pip install -r requirements.txt
jupyter notebook tiredness_analysis.ipynb
```

Then run all cells. Figures are saved to `figures/` and result tables to `results/`. K-means uses `random_state=42`, so the results are reproducible.

## Results
- No single habit is strongly correlated with tiredness (largest |ρ| ≈ 0.3, for daily steps, screen time and sleep hours).
- Sleep is the most consistent factor: the average of the last three nights (ρ = −0.43, p = 0.003) is more related to tiredness than the previous night alone (ρ = −0.29, p = 0.05).
- Party and sick days have a strong influence on the results. Without them, the relationship with sleep becomes stronger (ρ = −0.48) and the negative correlation of study hours mostly disappears.
- Gym time shows no relationship with tiredness, so two of my initial hypotheses (studying more and exercising more make me more tired) were not supported.
- K-means clusters mostly reproduce my weekly routine (weekdays, nights out and quiet days), and tiredness does not differ significantly between them.

The full interpretation and limitations are explained in the report (`report/report.pdf`).
